## 1. 环境准备

```bash
cd D:\Project\光机所项目\download_scripts
uv sync
```

首次使用 GEE 需要完成认证（只需一次）：

```bash
earthengine authenticate
```

浏览器会弹出 Google 登录页面，按提示授权即可。

## 2. 快速开始

### CLI 命令行

```bash
# 下载单点 64 波段嵌入向量（默认 2024 年，first 合成）
uv run se-cli -c "108.95,34.25" -p <项目ID>

# 批量下载多个点
uv run se-cli -c "108.95,34.25;116.40,39.90;121.47,31.23" -p <项目ID>

# 从 CSV 文件读取坐标
uv run se-cli -c coords.csv -p <项目ID>

# 跨年 mean 合成（自动 L2 重归一化）
uv run se-cli -c coords.csv -p <项目ID> --years 2020,2021,2022,2023,2024 --cross-year mean

# 选择指定波段子集
uv run se-cli -c "108.95,34.25" -p <项目ID> --bands A00,A01,A10,A11 --cross-year median

# 列出已下载文件
uv run se-cli --list -o ./output
```

### WebUI

```bash
uv run se-web
```

浏览器打开 **http://127.0.0.1:8001**。

## 3. 获取 Google Cloud Project ID

### 3.1 什么是 Project ID

Google Cloud 所有资源都归属于一个项目 (Project)，每个项目有唯一 ID，形如 `my-earth-engine-project`。

### 3.2 创建步骤

1. 打开 [Google Cloud Console](https://console.cloud.google.com)
2. 项目选择器 → **新建项目**
3. 输入项目名称，系统自动生成 Project ID
4. 启用 Earth Engine API: https://console.cloud.google.com/apis/library/earthengine.googleapis.com
5. 注册 Earth Engine: https://signup.earthengine.google.com

## 4. 坐标输入方式

### 4.1 命令行字符串

```bash
uv run se-cli -c "lon1,lat1;lon2,lat2;lon3,lat3" -p <项目ID>
```

- 坐标对用 `;` 分隔，经纬度用 `,` 分隔
- 经纬度范围: lon ∈ [-180, 180], lat ∈ [-90, 90]，超出自动跳过

### 4.2 CSV 文件

必须包含 `lon` 和 `lat` 列，`name` 列可选。以 `#` 开头的行和空行会被跳过。

**模板（最简）**：
```csv
lon,lat
108.95,34.25
116.40,39.90
```

**模板（含名称）**：
```csv
lon,lat,name
108.95,34.25,西安
116.40,39.90,北京
121.47,31.23,上海
```

### 4.3 WebUI 上传 CSV

上传 CSV 文件后会自动解析并填入坐标文本框，无需手动粘贴。

## 5. 全部命令行参数

| 参数 | 简写 | 默认值 | 说明 |
|------|------|--------|------|
| `--coords` | `-c` | 无（必填） | CSV 路径或 "lon,lat;lon,lat" |
| `--project` | `-p` | 无（必填） | Google Cloud Project ID |
| `--output` | `-o` | `./output` | 输出目录 |
| `--year` | `-y` | `2024` | 单年份下载（2017-2024） |
| `--years` | | 无 | 多年份逗号分隔，如 `2020,2022,2024`（优先级高于 `--year`） |
| `--buffer` | `-b` | `640` | 缓冲区半径（米） |
| `--bands` | | `all` | `all`（全部 64 波段）或逗号分隔如 `A00,A01,A10` |
| `--scale` | `-s` | `10` | 空间分辨率（米/像素） |
| `--crs` | | 自动 | 输出坐标系（默认自动根据坐标选择 UTM 投影） |
| `--format` | `-f` | `GEO_TIFF` | `GEO_TIFF` / `ZIPPED_GEO_TIFF` / `NPY` |
| `--cross-year` | | `first` | 跨年合成策略：`first` / `mean` / `median` |
| `--list` | | | 列出已下载文件 |

> **与 Dynamic World 的关键差异**：SE 使用 `--year` / `--years`（替代 `--start-date` / `--end-date`），使用 `--cross-year`（替代 `--composite`），无 `--file-per-band`（始终输出单文件），无 `--info`（64 维向量无可视化语义）。

## 6. 波段与合成方式

### 6.1 Satellite Embedding V1 数据集

| 属性 | 值 |
|------|-----|
| 数据集 ID | `GOOGLE/SATELLITE_EMBEDDING/V1/ANNUAL` |
| 波段数量 | 64（A00–A63） |
| 值域 | [-1, 1]，单位向量 |
| 空间分辨率 | 10m |
| 时间范围 | 2017–2024 年度合成 |
| 投影 | 本地 UTM（下载时自动重投影至指定 CRS） |

64 个波段是一个整体，代表地理位置的 64 维嵌入向量，各维度不可独立使用。

### 6.2 波段选择

| 参数值 | 说明 | 用途 |
|--------|------|------|
| `all` | 全部 64 波段（A00–A63） | 完整嵌入向量，推荐 |
| `A00,A01,A10,A11,…` | 指定波段逗号列表 | 仅需部分维度时使用 |

### 6.3 跨年合成策略

| 策略 | 说明 | L2 归一化 | 推荐场景 |
|------|------|-----------|---------|
| `first` | 取第一个年份的影像 | 不归一化 | 快速预览 |
| `mean` | 多年份取均值 | **自动 L2 重归一化** | **推荐**，多年信息融合 |
| `median` | 多年份取中位数 | 不归一化 | 抗异常年份 |

> **L2 重归一化说明**：多个单位向量的均值通常不再是单位向量。`mean` 合成后自动逐像素除以 L2 范数，确保输出仍为单位向量。零向量（极罕见）不做除法以避免 NaN。

### 6.4 缓冲区

`--buffer` 定义以坐标点为中心的圆形区域半径（米）。GEE 单次下载限制 ≤ 32MB（约 131,072 像素）。

| 场景 | 推荐 buffer | 估算大小（64 波段，10m 分辨率） |
|------|-------------|--------------------------------|
| 单栋建筑 | 100m | ~0.1 MB |
| 街区 | 500m | ~2 MB |
| 默认 | 640m | ~3 MB（安全） |
| 乡镇 | 1500m | ~18 MB |
| 大型区域 | 3000m | ~72 MB ⚠️ 可能超限 |

> 超过约 131,072 像素时会打印数据量警告，提醒减小 buffer 或增大 scale，但不会强制中断。

## 7. 坐标参考系 (CRS)

默认根据坐标自动选择 UTM 投影（EPSG:32601–32660 北半球 / EPSG:32701–32760 南半球）。极地区域（纬度 > 84° 或 < -80°）回退到 `EPSG:4326`。

| EPSG 代码 | 名称 | 适用区域 |
|-----------|------|---------|
| `EPSG:326XX` | UTM 北半球 | 北纬 0°–84°（默认） |
| `EPSG:327XX` | UTM 南半球 | 南纬 0°–80°（默认） |
| `EPSG:4326` | WGS84 | 全球（极地区域回退） |
| `EPSG:3857` | Web Mercator | Web 地图 |
| `EPSG:4490` | CGCS2000 | 中国大陆 |

> 原始数据为本地 UTM 投影，GEE 下载时自动重投影到指定 CRS。

## 8. WebUI 使用

### 8.1 启动

```bash
uv run se-web
```

浏览器打开 **http://127.0.0.1:8001**。

> 注意端口为 **8001**，与 DW WebUI 的 8000 不同，两者可同时运行。

### 8.2 页面功能

**认证区**：输入 Project ID，点击「初始化认证」。未认证时显示红色警告，引导先运行 `earthengine authenticate`。

**坐标输入**：
- 文本框粘贴坐标（分号分隔：`lon1,lat1;lon2,lat2`）
- 或上传 CSV 文件（上传后自动解析并填入文本框，显示坐标点数量和名称列表）

**下载参数**：
- **年份**：下拉框选择单年（2017–2024），或文本框输入逗号分隔的多年份（如 `2022,2023,2024`）。多年份优先级高于单年。
- **波段**：文本框输入（`all` 或逗号分隔如 `A00,A01,A10`）
- **合成策略**：下拉框选择 `first` / `mean` / `median`
- **缓冲区半径**：数字输入框（默认 640m）
- **空间分辨率**：数字输入框（默认 10m/像素）
- **输出格式**：下拉框选择 `GEO_TIFF` / `ZIPPED_GEO_TIFF` / `NPY`
- **CRS**：文本框（留空自动选择 UTM 投影）

**下载执行**：输出目录 + 开始下载按钮。进度条实时更新，每点完成后弹出通知（成功绿色 / 失败红色），页面底部显示逐点详细结果。

**已下载文件**：内置目录浏览器，支持查看 `.tif` / `.zip` / `.npy` 文件，显示文件名、大小、修改时间。支持子目录导航和刷新。

> **注意**：SE WebUI **提供** GeoTIFF 单波段灰度预览（切换 A00–A63 波段），但不提供 DW 那样的分类彩色图或波段统计功能（64 维向量无分类语义）。

**表单记忆**：关闭浏览器后重开，上次填写的所有参数自动恢复（包括 Project ID、坐标、参数选择）。

### 8.4 文件预览

已下载文件列表中的 `.tif` 文件右侧有「预览」按钮。点击后弹出弹窗：
- 显示选中波段的灰度预览图（值域 [-1, 1] → 黑白灰度）
- 下拉框可切换波段（A00–A63），预览图实时更新
- 需要 `rasterio` + `Pillow` 依赖支持

### 8.5 认证提示

首次使用若显示 "⚠ 未检测到 GEE 认证"：
1. 终端运行 `earthengine authenticate`
2. 在页面填入 Project ID 并点击「初始化认证」
3. 刷新页面

## 10. 常见问题

### Q1: "Caller does not have required permission"
Project ID 未启用 Earth Engine API。在 Cloud Console 中启用。

### Q2: "Earth Engine client library not initialized"
运行 `earthengine authenticate` 完成认证。

### Q3: 下载文件打不开
- `GEO_TIFF` → QGIS 打开，或用 `rasterio` 读取
- `ZIPPED_GEO_TIFF` → 先解压
- `NPY` → `numpy.load()`

Python 读取示例：
```python
import rasterio
with rasterio.open("all_first_E108.95_N34.25_2024.tif") as src:
    data = src.read()  # shape: (64, height, width)
```

### Q4: 区域过大报错
GEE 单次限制 ≤ 32MB。增大 `--scale` 或减小 `--buffer`。

### Q5: "跳过越界坐标"
坐标超出合法范围（lon ±180, lat ±90）。检查经纬度顺序，经度在前。

### Q6: "无可用影像"
该区域在指定年份无数据。数据集覆盖 2017–2024，确认坐标在陆地区域。

### Q7: 下载的 tif 是圆形的
这是 `buffer()` 产生的圆形 ROI，正常现象。像素值在圆形区域内有效，外部为 NoData。

### Q8: 为什么 SE 只能做灰度预览？
Satellite Embedding 是 64 维向量，每个波段值域 [-1, 1]，无分类语义。WebUI 支持单波段灰度预览（黑白灰度映射），可切换 A00–A63 任意波段查看。

### Q9: mean 合成的 L2 归一化是什么？
多个单位向量的均值不再是单位向量。`mean` 合成后自动逐像素做 L2 归一化（`v / ||v||`），恢复单位向量性质。`first` 和 `median` 不改变向量方向，无需归一化。

### Q10: 和 Dynamic World 下载器有什么区别？

| | Dynamic World | Satellite Embedding |
|------|------|------|
| 波段 | 1 或 9 | 64（整体使用） |
| 时间 | 逐景（双周） | 年度合成 |
| 时间参数 | `--start-date` / `--end-date` | `--year` / `--years` |
| 合成方式 | first/mosaic/mode/mean/median/collection | first/mean/median |
| 默认 buffer | 500m | 640m |
| WebUI 端口 | 8000 | 8001 |
| 预览功能 | 有（label 分类图） | 有（单波段灰度预览，切换 A00–A63） |
| 逐景下载 | 支持（collection 模式） | 不支持 |
| filePerBand | 可配置 | 始终 False（单文件） |
