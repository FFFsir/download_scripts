快速入口：

```bash
# 环境准备
uv sync
earthengine authenticate

# CLI 下载
uv run dw-cli -c "108.95,34.25" -p <项目ID> --composite mode

# WebUI
uv run dw-web   # 浏览器打开 http://127.0.0.1:8000
```
